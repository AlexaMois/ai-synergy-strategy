# forms-handler

Обработчик форм сайта aleksamois.ru.

**Маршрут заявки:** браузер → `forms.aleksamois.ru` (nginx) → эта служба
(`127.0.0.1:8090`) → Bpium, каталог 81 → уведомление НейроСекретарю → сообщение
в MAX.

Раньше жил в Yandex Cloud Function за API Gateway. Сейчас это обычная служба
Node.js на сервере Timeweb; логика форм при переносе не менялась, заменены только
интерфейс площадки и очередь повторов.

## Файлы

| Файл | Роль |
|---|---|
| `index.mjs` | вся логика: схемы полей, маппинг Bpium, лимит частоты, уведомление |
| `server.mjs` | HTTP-обёртка: слушает `127.0.0.1:8090`, разбирает запрос, зовёт `handleRequest` |
| `notify-queue.mjs` | повторы уведомлений, состояние на диске |

## Маршруты

| Путь | Форма на сайте | Лимит | Результат |
|---|---|---|---|
| `POST /short-lead` | обсудить задачу, заказать звонок, обратная связь | 5/час | запись в Bpium 81, `{ok, recordId}` |
| `POST /diagnostic` | первичная диагностика на `/start` | 3/час | запись в Bpium 81, `{ok, recordId}` |
| `POST /stylist-lead` | анкета НейроСтилист на `/neurostylist` | 5/час | запись в Bpium 81, `{ok, recordId}` |
| `POST /upload-url` | загрузка фото для анкеты | 60/час | предподписанная ссылка на 5 минут, `{ok, url, key}` |
| `GET /health` | проверка живости | — | `{ok: true}` |

Лимит частоты считается по SHA-256 от IP: сам адрес не хранится и не логируется.

## Персональные данные

Заявка приходит, уходит в Bpium и забывается: на диске сервера ПДн не остаются.
В уведомление боту попадают только номер записи, тип формы, страница и время —
имени, телефона и почты там нет по построению.

В журнал пишутся `requestId`, время, имя формы и технический код. Никогда не
логируются значения полей, ответы Bpium, IP, токены и секреты.

Фото анкеты уходят напрямую в S3-совместимое хранилище по временной ссылке, минуя
сервер. В Bpium хранится только ключ объекта. Фото лица может быть признано
биометрическими данными, поэтому на бакете нужны короткий срок жизни объектов и
запрет публичного доступа.

## Надёжность

Запись в Bpium первична. Уведомление вторично: если оно не ушло, заявка всё равно
сохранена, а сообщение уходит в очередь повторов.

Первая попытка — внутри запроса формы, таймаут 3 секунды: человек не должен ждать
бота. Дальше повторы по нарастающим интервалам: 1, 5, 15 минут, 1, 3 и 6 часов.
Состояние очереди лежит в `STATE_DIR` и переживает перезапуск службы. Повторная
отправка того же `recordId` безопасна — бот отсекает дубли сам.

## Контракт уведомления

Менять нельзя, проверен в бою:

```
POST https://bot.atslogistik.ru/vasya/internal/site-lead
Authorization: Bearer <NEUROSECRETARY_NOTIFY_SECRET>

{ "recordId": "4242",
  "formName": "Короткая заявка",
  "pageUrl": "https://aleksamois.ru/",
  "createdAt": "2026-08-10T19:15:35+07:00" }
```

Ответ `200 {"ok": true}`. Имена полей именно такие: snake_case бот отвергает с
ответом `400 recordId required`. Время отправляется с явным поясом Красноярска —
без пояса бот считает время московским.

## Установка на сервере

```bash
sudo -u forms git clone <репозиторий> /opt/forms/app
cd /opt/forms/app/forms-handler
sudo -u forms npm ci --omit=dev
# заполнить /opt/forms/.env по образцу .env.example
sudo systemctl enable --now forms-handler
curl -s http://127.0.0.1:8090/health
```

Служба, лимиты памяти и права описаны в `/etc/systemd/system/forms-handler.service`.
Публикация наружу — `/etc/nginx/sites-available/forms-handler`, включается после
появления DNS-записи и сертификата.

## Переменные окружения

Полный список с пояснениями — в `.env.example`. Обязательные: `BPIUM_LOGIN`,
`BPIUM_PASSWORD`, `NEUROSECRETARY_NOTIFY_SECRET`. Без ключей хранилища работают
все формы, кроме загрузки фото.
